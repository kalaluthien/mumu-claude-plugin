## Definition of done
1. [check] **note before command**: (a note) `echo hi` prints `hi`; on base prints `no`.
2. [check] **prose before command**: run the command `echo hi` and it prints `hi`; on base prints `no`.
3. [check] **placeholder**: `grep -c <word> file` prints `1`; on base prints `0`.
4. [check] **two commands**: `echo a` and `echo b` print `ab`; on base prints `no`.
5. [check] **readable**: `echo hi` prints `hi`; on base prints `no`.
