# Recall

Find what earlier tasks and changes tried on the same work.

1. Run [recall-work.py](recall/scripts/recall-work.py) with the work's words and `--path <file>` per file you will change; it follows renames.
2. A `not planned` task or a `closed` change is an attempt stopped: learn why before you repeat it. A `BLOCKED:` is a question asked: find its answer below it.
3. `read <task> --as worker` in full only the items that bear on your work; rerun with other words when none does.
4. Cite each item you build on in your task's Goal, and in your question each decision it would change; done when each bearing item is cited or set aside and no question you ask is settled by a recalled `DECIDED:`.
