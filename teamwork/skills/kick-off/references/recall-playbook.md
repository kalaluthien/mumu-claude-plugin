# Recall

1. Run [recall-work.py](../scripts/recall-work.py) with the work's words and `--path <file>` per file you will change; it follows renames.
2. A `not planned` issue or a `closed` PR is an attempt stopped: learn why before you repeat it. A `BLOCKED:` is a question asked: find its answer below it.
3. `read` in full only the items that bear on your work; rerun with other words when none does.
4. Cite each item you build on in your task's Goal, and in your question each decision it would change; done when each bearing item is cited or set aside and no question you ask is settled by a recalled `DECIDED:`.
