# Criteria

Write a criterion a stranger can check, with the same verdict each time.

## Rules

- **One proposition**: one fact per criterion; split a compound one, since compound and implied criteria are where scores get gamed (https://arxiv.org/abs/2605.12474).
- **Positive**: state what a good target holds, so met is always good.
- **Condition, not judgement**: write what makes it true; a vague word such as "clear" needs `anchors` saying what counts.
- **Observable**: the target alone decides it; only what it states counts.
- **Program first**: when a command can decide it, make it a program check, since a command does not drift.
- **Absence**: a criterion over a set, such as each option described, is marked `absence`, so a judge lists the items before checking them.
- **Binary**: met or not, since checklists raise agreement between judges and with people (TICK, https://arxiv.org/abs/2410.03608).
- **Provenance**: `from` names the framework or flaw it came from.
- **No credit for length**: none rewards amount, since judges favour longer answers (MT-Bench, https://arxiv.org/abs/2306.05685).
- **Critical**: mark only what the target exists to do; each critical gap caps the rating.
