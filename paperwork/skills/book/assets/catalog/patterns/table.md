# table: rows and columns that carry the comparison, so the reader finds a cell and reads across or down
family: visual
elements: raw, alt
differs: the claim lives in the grid itself (which cells are filled, which are empty), read by row and column. isotype counts drawn marks; small-multiples repeat a plot; neither makes the reader look up a cell
Hand markup: no element draws a table, so it is `raw` with `alt` (keeps markup lint, gets no element checks). A new `table` element can be proposed in the plan.

## Why it works
When two or more criteria cross, prose makes the reader hold a grid in mind. A table puts the grid on the page, and an empty or marked cell is the finding. It prevents a paragraph that lists every combination in turn (fig-data).

## Parts
- raw: a real table with header cells for rows and columns, and a short first column; one mark vocabulary for filled and empty cells.
- alt: says what the rows and columns are and which cell or row the point rests on.

## Examples
Source book: the UX book (ids are its card or figure ids, with the unit in parentheses).
- fig-chat-media-table (u-chat): eight media constraints as rows against face to face, phone, messenger and an assistant as columns. Essential content: the assistant has four of the eight and lacks the four that need presence.
- fig-compose-owner-table (u-compose): three eras of a static element system (search page 2007, server-driven UI 2016, model with a catalog 2024) against who decides to show, fill and place it. Essential content: the deciding party moves from a learned mixing function and backend code to the model with a validator.
- fig-rec-forms-table (u-record): four fields of practice against the three forms of record each uses. Essential content: the same three forms recur in every field.
Elsewhere: A plan comparison with features as rows and tiers as columns, the first missing feature of the cheap tier marked.

## Compose and vary
- Combines with: annotated-exhibit (numbered cells), mock-screen (a cell holds a drawn part).
- Vary: rows are cases and columns are criteria, or the reverse; keep one mark vocabulary and at most about eight rows.
- Usual failure: the table repeats what the sentence beside it says, or its cells need a legend to be read.

## Seed
Is the point a cell or a pattern of cells that a paragraph would hide?
