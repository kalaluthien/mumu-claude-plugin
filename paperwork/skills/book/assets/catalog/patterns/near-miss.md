# near-miss: a case one condition short of the rule tests the rule, not its keyword
family: problem
elements: setup, near-miss, exhibit, answer, rival

## Why it works
The reader sees a case that has every familiar sign of the rule except one condition. Naming the rule is not enough; the reader must check the condition. It prevents answers given by resemblance (card-claim, card-new-case).
The missing condition (`missing`) is also the reason a rival fails, so the why can break the belief by one fact (card-why).

## Parts
- setup: states the rule's conditions in the unit's words, so the absent one can be checked.
- near-miss: `missing`, the one absent condition; it appears as a rival or as an exhibit variant, never as the stem's hint.
- exhibit: shows the case, with the condition checkable in it.
- answer / rival: the answer says which condition fails; rivals each fail a different, already-satisfied condition.

## Examples
Source book: the UX book (ids are its card or figure ids, with the unit in parentheses).
- ask-prim-dark (u-primitive): a signup layout has a problem, a context and a solution, yet is not a pattern. Essential content: the "problem" belongs to the company, not to the people using it, so the condition "solves a recurring user problem" is the absent one.
- ask-per-exempt (u-percept): three pale parts; the logo and the disabled control are exempt from the contrast floor, the timestamp is not. Essential content: the exemptions are conditions, not exceptions to remember.
- ask-per-panel (u-percept): spacing is kept equal and a background panel is added around a pair. Essential content: equal distance is neutral, so the new cue decides the grouping.
Elsewhere: A loan offer meets four of five tests for "fair terms"; the card asks which test it fails.
# Compose and vary
- Combines with: spot-defect, explain-why, compare-designs.
- Vary: choose a rule with an enumerable set of conditions, then remove one; rotate which condition is missing across the unit.
- Usual failure: the missing condition is also what the stem states, so the card refutes the rival in the question (card-rival).
