# probe-before-reveal: ask what a newcomer expects before the idea is given, so the idea corrects a real belief
family: problem
elements: stem, answer, rival

## Why it works
A probe asks the question in a newcomer's words, before the unit has explained, so the reader commits to a prior model. The following section then repairs that model, and the options are the models people actually hold (card-probe). It prevents cards that only reward remembering the preceding paragraph.
Every option is a real prior: a first-order guess, a plausible rule from elsewhere, and the right pattern in plain words (card-rival).

## Parts
- stem: a situation, no technical term the unit has not yet given; one open question about outcome or cause.
- answer: the correct model in plain words; why explains it without naming the unit's vocabulary.
- rival: two prior models, each with a `belief` the section will name and correct.

## Examples
Source book: the UX book (ids are its card or figure ids, with the unit in parentheses).
- probe-human-width (u-human): the width of a tapped button is halved at fixed distance; time to tap? Essential content: the extra time is a constant added per halving, not a doubling.
- probe-cmd-stop (u-command): several ways to stop a run could be built; which is best? Essential content: menus for the rare user and a command line for the daily one, both kept, since each is cheapest for a different person.
- probe-docs-skim (u-docs): a team lead skims a post-mortem for thirty seconds and closes it; what must the report do first? Essential content: the conclusion and the ask come before the evidence.
Elsewhere: Before teaching compound interest: "doubling the time you save, what happens to the final sum?"
# Compose and vary
- Combines with: compare-designs and intervene as the opening card of a section.
- Vary: use the audience's words, one unit per probe, and put it before the first paragraph that explains.
- Usual failure: the probe names the unit's term, or the right option is the only one a newcomer would never pick.

## Seed
Would a newcomer choose each wrong option for a reason they could state, using none of the unit's terms?
