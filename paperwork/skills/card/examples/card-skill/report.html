What was graded

Kind
a Claude Code skill: SKILL.md, playbooks, scripts and a page template
Purpose
grade any target into an HTML report card: find its subject, derive a rubric, grade it with evidence, show the page (https://github.com/kalaluthien/mumu-claude-plugin/issues/1046)
Reader
the owner, who reads the report card, and the agents that run the skill; a wrong or unreadable card sends the owner to fix the wrong thing
Criteria drawn from
  • the owner's ask, https://github.com/kalaluthien/mumu-claude-plugin/issues/1046
  • Anthropic's skill best practices, https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices
  • the repository's skill rules, AGENTS.md
  • research on rubric grading and report design, cited in references/report.md
Rubric
Grade one Claude Code skill folder against the owner's ask: given a target, the skill finds the target's subject, derives a rubric, actually grades the target and writes a graded HTML report. Judge from the folder's files alone.

Each criterion is one yes-or-no check. sonnet graded every criterion in 2 fresh runs that saw only the target and the rubric, quoting its evidence before each verdict; when runs split, the stricter verdict counts.

The judge’s error rate per tier is estimated, not measured on human labels. Read the tier counts as an order between versions of a target, not as a percentage of quality.
