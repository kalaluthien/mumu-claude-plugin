# Contributing

- **Issue first**: open an issue that says what should change and why; your pull request cites it.
- **Fork**: push a branch to your fork and open the pull request against `main`; it lands as one squashed commit.
- **The owner merges**: the owner's sessions review your pull request at its head commit and the owner merges it, since you cannot.
- **Code is read line by line**: the owner's sessions run these plugins straight from `main`, so a change to a hook, monitor, script, `lib/` or `bin/` waits for the owner to read every line; keep it small.
- **Comments are discussion**: the team's sessions act only on the owner's and collaborators' `BLOCKED:` and `DECIDED:` comments, so yours never assign or answer work.
- **Rules**: [AGENTS.md](AGENTS.md) holds the rules every change follows.
