# Spec: setup

A repo with no model: model the modules the change touches in Alloy, as one drawable map.

1. Look for a model and the checker: [spec/layout-playbook.md](spec/layout-playbook.md). With no `alloy`, stop there.
2. Initialise the map, `map.als` in the repo's `spec/`, and a `model.als` and `check.als` per module the change touches: [spec/model-playbook.md](spec/model-playbook.md).
3. Check it: [spec/check-playbook.md](spec/check-playbook.md).
4. Tell the owner "no spec layout found; initialised spec/".
