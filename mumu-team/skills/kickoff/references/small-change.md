# Small change

The one change a lead makes itself.

A small change: the owner's words already spell it out, in one file and about 5 changed lines, with no script logic (text, frontmatter or configuration). Make it yourself in a worktree off the default branch, `pr` it on the task reopened or filed for it, launch the `reviewer` on it with the model `review-model.py` prints, `merge` it at its `APPROVED:` head, and remove the worktree and branch as `clean` does.
