# Status

Report where a goal stands, changing nothing.

1. Find each parent: your mission's `Mission:` lines, else a parent or issue url in the text, else ask with `AskUserQuestion`.
2. `read` each parent, then each of its sub-issues and its pull request.
3. `live`, matching each worker to its issue by its `Worker:` line or its name.
4. Report one row per issue: its state on GitHub, its pull request, and its worker's `agent_status`, or none.
