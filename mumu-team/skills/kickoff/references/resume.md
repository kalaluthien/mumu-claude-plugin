# Resume

Continue this session's work from GitHub.

1. A leader finds the root goals it holds with `gh issue list --label goal --state open --search "no:parent-issue" --json number,title,url`, run in its checkout; a worker's task is the `<n>` of its worktree `<topic>-<n>-<k>`.
2. `live`, then `read` each root goal, the goals and tasks under it, and each task's pull request.
3. A leader continues at Lead 4 of [lead.md](lead.md), acting on each open task as if its notice had arrived.
4. A worker continues at the step of [work.md](work.md) its task and pull request show: no claim is 1, no pull request is 3, a pull request not merged is 4, merged is done.
