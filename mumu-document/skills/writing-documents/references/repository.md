# Repository page

- Markdown where the repository keeps pages (a README, `docs/`), linked from
  its README, landed by its own procedure: a branch and a pull request.
- The moves are headings; each widget is its markdown column in the mapping.
- A figure is an SVG file committed beside the page and linked as
  `![alt](<name>.svg)`, exported as [github.md](github.md) says; its alt says
  what the figure shows in one sentence.
- Each `path:line` is a relative link, so it follows the branch it is read on.
