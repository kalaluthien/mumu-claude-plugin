# Security

Report a vulnerability privately through GitHub's private vulnerability reporting: open the form at https://github.com/kalaluthien/mumu-claude-plugin/security/advisories/new. Never put it in a public issue, a comment or a discussion, since anyone can read those before a fix lands.

Include:

- the plugin and the file, such as a hook, monitor or script, with the commit or release you saw it in;
- what an attacker can do, and what they need first;
- the steps or a minimal input that shows it;
- your macOS, Claude Code and Python versions, when they matter.

The owner answers in the advisory and credits you there once a fix lands, unless you ask not to be named.
